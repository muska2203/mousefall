# Промпт-шаблон для одиночной генерации спрайта
#
# Как пользоваться:
# 1. Отправь генератору: СТИЛЬ-БЛОК + одну строку объекта из списка ниже.
#    Один запуск — один спрайт. Никаких размеров и разрешений в текст не
#    добавлять — генератор рисует в своём стандартном разрешении, а явные
#    пиксели заставляют его «сверять» картинку с размерами и портят результат.
# 2. Полученную картинку уменьши до 128×128 и сохрани в нужную папку
#    public/assets/ поверх болванки.
#
# Почему промпт устроен именно так:
# - Читаемость при уменьшении задаётся относительными формулировками
#   (толщина линии как доля от ширины объекта), без чисел в пикселях.
# - Стиль-блок полностью самодостаточен: никаких отсылок к «референсным
#   спрайтам», которых генератор не видит.
# - Запреты собраны в одну короткую строку — длинные перечни «без …»
#   разбавляют основной сигнал.

────────────────────────────────────────
СТИЛЬ-БЛОК (обязательный, копировать целиком)
────────────────────────────────────────

Нарисуй один игровой спрайт-иконку для 2D top-down RPG в стиле stylized dark fantasy. Спрайт будет сильно уменьшаться для показа в интерфейсе, поэтому рисуй сразу «под уменьшение»: только крупные формы и толстые линии.

Стиль:

- Сел-шейдинг: плоская заливка с 3–4 чёткими ступенями полутона, без мягких градиентов и аэрографии.
- Контур: толстая ровная тёмная (почти чёрная) обводка по всему силуэту и вокруг каждой крупной внутренней детали. Толщина линии — не меньше одной шестидесятой от ширины объекта; тонких штрихов быть не должно вообще.
- Формы: объект собран из 3–7 крупных читаемых силуэтов. Без мелкой детализации, орнаментов и текстур поверхности.
- Цвет: приглушённая, чуть холодная dark-fantasy палитра; яркий акцент допустим только один — на главной «фишке» объекта (свечение, капля, пламя).
- Освещение: ровное, ненаправленное, без теней.
- Композиция: ровно один объект, строго по центру, целиком в кадре с небольшим полем по краям, вид в 3/4 спереди и слегка сверху.
- Фон: полностью прозрачный. Если прозрачность недоступна — плоский однородный серый #808080.
- Запрещено: текст, буквы, цифры, рамки, водяные знаки, второй объект, сцена/окружение, тень на фоне.
ВАЖНО. При необходимости перегенерации создавай новые файлы, чтобы старые тоже сохранились. Если есть водяной знак, но он не попадает на основную картирку, не нужно пытаться его удалять.
