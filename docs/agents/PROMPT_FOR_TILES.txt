# Промпт-шаблон для одиночной генерации ТАЙЛА (террейн)
#
# Отличие от PROMPT_FOR_SPRITES.txt: тайл — это фон игрового пространства.
# Он НЕ должен привлекать внимание и конкурировать со спрайтами юнитов,
# предметов и статусов. Поэтому здесь: никакой обводки, низкий контраст,
# приглушённые цвета, крупные мягкие формы.
#
# Как пользоваться:
# 1. Отправь генератору: СТИЛЬ-БЛОК + одну строку тайла из списка ниже.
#    Один запуск — один тайл. Никаких размеров и разрешений в текст не
#    добавлять — генератор рисует в своём стандартном разрешении.
# 2. Полученную картинку уменьши до 128×128 и сохрани в public/assets/tiles/
#    под именем террейна (floor.png, sand.png, wall.png).
#
# Проверка результата: поставь тайл рядом сам с собой 2×2 — стыков не должно
# быть видно; положи поверх любой спрайт юнита — юнит должен читаться легко,
# тайл не должен «спорить» с ним по контрасту.

────────────────────────────────────────
СТИЛЬ-БЛОК ДЛЯ ТАЙЛОВ (обязательный, копировать целиком)
────────────────────────────────────────

Нарисуй один бесшовный тайл фона для 2D top-down RPG в стиле stylized dark fantasy. Тайл — фон игрового поля: он должен быть спокойным и незаметным, не конкурируя по вниманию с персонажами и объектами поверх него.

Стиль:

- Вид строго сверху. Тайл заполняет весь кадр от края до края, без полей и рамок.
- Бесшовность: картинка должна стыковаться сама с собой со всех четырёх сторон без видимых швов; никаких крупных деталей, упирающихся в край только с одной стороны.
- Без обводки и контуров: никаких тёмных линий вокруг элементов — только мягкие переходы цвета и тона.
- Контраст низкий: разница между самым светлым и самым тёмным местом тайла — умеренная; без чистого чёрного и чистого белого.
- Цвет: приглушённая, чуть холодная dark-fantasy палитра, монотонная внутри тайла; без ярких акцентов, свечений и пятен, цепляющих взгляд.
- Формы: только крупные мягкие элементы (плиты, швы, волны); деталей должно быть мало и они не должны образовывать узнаваемый повторяющийся «паттерн-рябь».
- Шейдинг: мягкий, 2–3 ступени полутона; освещение ровное и ненаправленное, без теней и источников света.
- Композиция: без центрального объекта и фокальной точки — равномерная поверхность.
- Запрещено: текст, буквы, цифры, рамки, водяные знаки, отдельные предметы, мусор, персонажи, яркие блики.
