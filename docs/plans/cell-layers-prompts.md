# Промпты для выполнения фаз плана «Слоистая модель клетки»

> Готовые промпты для запуска AI-агентов. Каждый промпт самодостаточен: агенту не нужен контекст предыдущих обсуждений.

- Форма реализации «после срабатывания»: новый RuleEffect на удаление объекта-владельца правила или выделенный интент DESTROY_OBJECT + исполнитель — выбери по согласованности с тем, как устроены эффекты правил после фазы 4.

- Ловушка — объект (сущность), а не тайловый эффект: у неё идентичность, скрытость и состояние срабатывания.

- Скрытая ловушка срабатывает, но не отображается; обнаружение — только срабатыванием и в debug-режиме; механика поиска и обезвреживание отложены (решение 2026-07-30).
- Слот размещения ловушки — floorFixture (фаза 4).

Обязательно проверь тестом: скрытая ловушка не влияет на автопуть игрока (путь через клетку со скрытой ловушкой строится и ход выполняется — срабатывание происходит по факту входа).

После завершения реализации:
1. Запусти npm run typecheck, npm test, npm run validate:content — всё должно быть зелёным.
2. Отметь фазу 5 как выполненную в таблице «Прогресс» в docs/plans/cell-layers-migration.md (с пометками о принятых решениях).
