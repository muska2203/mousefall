# Концепт контента первого этажа (MVP)

> **Статус:** `[DRAFT]` — рабочий концепт до начала реализации. Числовые значения черновые; баланс — отдельным проходом с плейтестом (roadMap 1.4).
>
> **Назначение.** Целевой начальный сетап первого этажа: противники, стартовые предметы, бафы/дебафы, способности, реликвии и игровые объекты. Текущий набор правил, предметов и способностей — тестовый (проверка механик движка, см. `mechanics-overview.md` §4); этот документ фиксирует, что должно войти в MVP этажа 1 (roadMap 1.2, 1.4).
>
> Связанные документы: [`roadMap.md`](../../roadMap.md) (этап 1), [`mechanics-overview.md`](./mechanics-overview.md) (доступные ручки и пробелы), [`first-boss-concept.md`](./first-boss-concept.md) (босс этажа).

---

## 1. Рамка

- **Тема этажа:** подземелье замка. Антуражные объекты: бочки с маслом, мышеловки, мешки с мукой, взвешанная мука (взрывоопасная, мешает обзору).
- **Две линии сборки** (могут пересекаться):
  1. **Подвижный боец** — физический урон через мечи: кровотечения, рывки, взмахи.
  2. **Алхимик** — урон через окружение и расходники: масло, огонь, мука, бомбы, праща.
- Пересечения линий (намеренные): огненное оружие бойца поджигает масло/муку алхимика; дым и мука — укрытие для обоих; толчки и столкновения (урон + `dazed` глобальными правилами) работают для обеих линий.

## 2. Принятые решения (2026-08-13)

- Взвешанная мука — **только временный эффект из источников** (мешки с мукой, расходники); отдельного спавна генератором нет.
- **Мышеловка:** урон + кровотечение + обездвиживание на 2 хода. Скрытые ловушки обнаруживаются **активным поиском за AP**.
- **Старт забега:** 2 шаблона персонажа (Боец / Алхимик) с разными стартовыми предметами и разными пулами реликвий на выбор. Алтарь выбора реликвии **убран из стартовой комнаты** (2026-08-26, вместе с реализацией п.8 §3): из типа комнаты `start` убран `guaranteedPois: [relic_altar]` (поле `MapParams.startPoiId` удалено 2026-08-14 — алтарь задавался типом комнаты). Выбор стартовой реликвии — на экране создания персонажа.
- **Мука и обзор:** облако блокирует LOS сквозь себя (как дым) **и** скрывает сущности внутри: сущность на клетке с мукой видна наблюдателю только с дистанции ≤ 1 (симметрично для игрока и AI).
- **Обездвиживание (`rooted`)** блокирует только самостоятельное перемещение (MOVE, рывок, прыжок, телепорт); атаки и способности по целям в досягаемости разрешены. Внешние перемещения (толчок) не блокируются — жертву можно выбить из мышеловки пушем.
- **Прыжки** из линии Бойца убраны — зарезервированы для молотов в будущем. Вид `swoop` остаётся в движке (босс), не удалять.
- **Экипировка MVP:** оружие — 2 вида (мечи, праща); броня — тяжёлая и лёгкая; амулет — один («Тусклая бусина»).
- **Баланс** (значения статусов, бюджет лечения, иммунитеты врагов) — отдельным проходом, как зафиксировано в roadMap 1.4.

## 4. Контент

После движковых пунктов создаётся без изменения кода (по рецептам `docs/recipes/`, проверка `npm run validate:content`).

### 4.1 Статусы

- `bleeding` — дебаф, тик физического урона, категория `wound` (отдельная, чтобы не конфликтовать с другими статусами при совместном наложении одним событием).
- `rooted` — дебаф, блокировка перемещения (семантика §2), категория `control` (отдельная по той же причине: мышеловка накладывает bleeding + rooted одним батчем).
- Существующие 11 статусов остаются; ребаланс — в балансном проходе.

### 4.2 Тайловые эффекты

- `flour_cloud` (взвешанная мука) — **реализован (2026-08-20)**: слой `aboveGround`, `blocksLOS: true`, `concealsEntities: true`, временный (длительность 4), **взрывается от огня** (поле `explosion`: triggerStatus `burning`, 5 урона, радиус 1, `consumesEffect: true` — обобщённая реакция п.7 §3); поджог — правила `fire_damage_ignites_flour` / `fire_tile_damage_ignites_flour` (копии масляных). Числа черновые.
- Существующие `water`, `oil`, `smoke` остаются.

### 4.3 Оружие (2 вида)

- **Мечи** (subtype `sword`, 2–3 шаблона): фирменный модификатор «кровотечение при ударе» (правило по тегу `damage.physical.slashing`, образец `weapon_poison_on_hit`); способности — `dash` и взмах (`cleave`); добивание по кровоточащим — правило `modifyDamage` при `hasStatus bleeding` (на втором мече или в пуле аффиксов).
- **Праща** (subtype `sling`, 1–2 шаблона; `sling` добавлен в `WEAPON_SUBTYPE_IDS` 2026-08-19). Роль — не «лук», а инструмент дистанции и доставки алхимии: основной урон линии Алхимика — окружение, праща даёт безопасную дальность и контроль. Кит (решения 2026-08-18, числа черновые) — **контент реализован 2026-08-19**: шаблон `common_sling`, способность `stone_throw`, модификатор `mod_sling_throw_range`:
  - **Базовая атака дальняя** (п.9 §3 выполнен 2026-08-19): range 5, min-range 2, LOS; урон {2,3} `damage.physical.blunt`, теги `delivery.weapon` + `attack.ranged`. Следствия существующих правил: критует по `dazed`/`stunned` (`delivery.weapon`), подхватывает `weapon_blunt_daze` (контроль встроен в базовую атаку), не ловит мили-правила с фильтром `attack.melee` (шипы брони, восстановление AP) — намеренно. С 2026-08-19 дистанции — Чебышёв (roadMap 1.6): min-range 2 отсекает все 8 соседних клеток, bump в упор отклоняется валидацией (без деградации в unarmed).
  - **«Бросок камня»** (`throw`, п.10 §3): плоский урон 3 (`baseDamage`; решение 2026-08-19 — консистентность с плоским уроном union-видов `groundSlam`/`swoop`) + толчок на 1 клетку, кулдаун 2, 1 AP; камни — бесконечный боеприпас. Роль — столкновения (5 blunt + `dazed` глобальными правилами) и выбивание врагов в масло/мышеловки/мучные облака. С 2026-08-19 таргетинг — только по 8 лучам-направлениям от кастера (как у рывка), толчок строго вдоль луча (roadMap 1.6).
  - **Фирменный модификатор `throwRange +5`** (после п.11 §3) — пассивная дальнобойность бросков расходников: базовая дальность бросков снижена до 2 (§4.6), праща возвращает её до 7. Второй активный скилл для roadMap 1.1 — через `abilityPool` (по образцу `common-school-wand`); содержимое пула решено 2026-08-19: только `dash` (мобильность под роль «инструмент дистанции», не требует `attack.melee`).

### 4.4 Броня (2 весовых класса)

- **Тяжёлая** (1–2 шаблона): высокий `baseArmor`; защитный скилл selfBuff («Стойка»: статус с модификатором брони на N ходов). Вариант «краткая неуязвимость по образцу `bulwark`» отложен как балансно спорный для игрока.
- **Лёгкая** (1–2 шаблона): низкая/нулевая броня; скиллы-бафы на передвижение (+AP на N ходов — зависит от п.13 §3) и урон (+урон на N ходов, чистый контент).

### 4.5 Амулет (1)

- **«Тусклая бусина»**: случайный +1 к одной из четырёх характеристик (`str`/`dex`/`int`/`vit`). Реализация через систему аффиксов: 4 stat-модификатора с `applicableSubtypes` только на подтип этого амулета; ролл экземпляра выбирает один. Стандартный шанс негативного аффикса при ролле принят как фича (решение 2026-08-13) — отдельный флаг отключения не нужен.

### 4.6 Расходники

- Новые: ~~**мешочек муки**~~ — реализован 2026-08-20 (`flour_pouch`: `spawn_tile_effect` → `flour_cloud`, радиус 1, дальность 2 по решению о базовой дальности ниже), ~~**зажигательная бомба** и **осколочная бомба**~~ — реализованы 2026-08-20 (`incendiary_bomb`/`frag_bomb`, эффект `damage`, п.2 §3).
- Существующие: `oil_bottle`, `smoke_bomb`, `water_ball`, `health_potion` (лечение — дефицитный ресурс, roadMap 1.4).
- **Базовая дальность броска метаемых расходников — 2 клетки** (решение 2026-08-18): снизить `range` в шаблонах `oil_bottle`/`smoke_bomb`/`water_ball` (сейчас 5; чистый контент). Дальние броски — привилегия пращи через фирменный `throwRange +5` (§4.3).

### 4.7 Игровые объекты

- **`oil_barel`** — есть; спавнится генератором через `propPool` типов комнат (2026-08-14).
- **`flour_bag`** (мешок с мукой) — **реализован (2026-08-20)**: проп с тегом `contains.flour` + `flammable` + два правила разлива `prop_contains_flour_spills_on_death` / `flammable_flour_bag_explodes_on_fire_death` (точные копии масляных из `global-rules.ts`; горящий мешок детонирует облаками с `burning`). Добавлен в `propPool` типа комнаты `normal`.
- **`mousetrap`** (мышеловка) — **реализована (2026-08-23)**: `initiallyHidden`, `oneShot`; три правила на триггере `ENTITY_MOVED` (слой `object`, образец `spikes`) — `mousetrap_deal_damage` (8 `damage.physical.piercing`), `mousetrap_apply_bleeding` (3 хода), `mousetrap_apply_rooted` (2 хода); обнаруживается «Поиском» (п.5 §3). ### 4.8 Реликвии

- Ревизия существующих 8 под две линии (сейчас перекос в огонь/яд — ветка Алхимика; у Бойца почти нет поддержки).
- **+2–3 под Бойца:** урон по кровоточащим (выразимо уже сейчас — `modifyDamage` при `hasStatus bleeding`); AP/лечение при убийстве — после п.12 §3.
- **+2–3 под Алхимика:** усиление урона окружения/горения, дальность броска расходников, стартовые расходники. `relic_salamander_heart` уже частично покрывает огненную ветку.
- Стартовые пулы реликвий — разные у двух шаблонов персонажа (п.8 §3).

### 4.9 Враги

- Пул этажа 1 (решение 2026-08-13): **только `cat_small` и `cat_mid`**. Новых врагов в MVP не добавляем; `cat_big` (элита) и новые тематические враги — возможно, после MVP.
- Иммунитеты/уязвимости врагов — в балансном проходе (теги/правила, контент).
- Босс `cat_guardian` реализован механически; инфраструктура босс-файта (`isBoss`/`bossPool`, босс-комната, запирающиеся двери) — roadMap 1.3, вне рамок документа.

### 4.10 Шаблоны игроков

- Два осмысленных шаблона (Боец / Алхимик) с разными `starterEquipment`, `starterRelicPool` и `baseStats`.
- Существующие 7 тестовых шаблонов — удалить или пометить тестовыми.
- Стартовый алтарь из `floor_1` убрать (§2).

### 4.11 Биом и параметры этажа

- Визуальный стиль «подземелье замка»: террейны/рескин `floor`/`wall`, ассеты.
- `MapParams` этажа 1: пулы врагов/предметов/пропов/ловушек, плотности (roadMap 1.2).
- Известная мёртвая ручка: поэтажные `relicPool` не работают (mapParams фиксируются на `floor_1`, §10.2) — для MVP одного этажа некритично.

## 5. Отложенные вопросы

Решены 2026-08-13: негативный аффикс у «Тусклой бусины» — принят как фича; радиус поиска ловушек — 3 клетки; пул врагов — только `cat_small`/`cat_mid`. Решён 2026-08-18 вопрос «Броска бомбы»: скилл убран вовсе — по итогам сравнительного разбора вариантов (двухшаговый скилл «выбери расходник → клетку», self-buff «Размах», пассивный стат, булев флаг, переиспользование `weapon.range` — последние два отклонены как захардкоженные/семантически связанные) выбран **пассивный фирменный стат `throwRange +5`** при снижении базовой дальности бросков до 2 (§4.3, §4.6, п.11 §3).

Отложенных вопросов не осталось. Поддержка `maxAp` в `statModifiers` статусов реализована 2026-08-26 (п.13 §3).
