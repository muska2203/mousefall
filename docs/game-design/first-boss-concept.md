# Концепт первого босса — «Кот-Страж»

> **Назначение.** Окончательный концепт механик первого босса (roadMap, этап 1.3). Документ заменяет исходную заготовку «щит/парирование» из `roadMap.md`: по итогам дизайна (2026-08-10) набор механик босса — трёхскилловый (Глухая оборона / Налёт / Удар по земле) с двумя стадиями боя. Отложенный вопрос «вариант щита» решён: периодическая активируемая неуязвимость (Глухая оборона), без пассивного снижения урона и без парирования.
>
> Числовые значения (HP, броня, уроны) — черновые; финальный баланс — отдельным проходом (roadMap 1.4).

---

## 1. Фантазия и роль

Тяжеловооружённый кот-страж первого этажа. Медленный, толстый, давящий. Обучает игрока читать телеграфы подготавливаемых скиллов, работать с геометрией (не стоять спиной к стене) и использовать окна уязвимости. Жизнеспособен против обоих стилей игрока: против ближнего боя — урон по площади и толчки, против дальнего — сближение Налётом и неуязвимость Глухой обороны.

Босс сражается в запертой босс-комнате (механика комнаты и дверей — roadMap 1.3, вне рамок этого документа).

## 2. Параметры (черновик, баланс позже)

- Основа — шаблон `cat_guardian`: HP ~90, высокая броня, `maxAp 3`, обычная мили-атака.
- Порог перехода стадий: **50% maxHp**.
- Шаблон получает флаг `isBoss` (roadMap 1.3), три способности (ниже) и новую AI-стратегию.

## 3. Способности

### 3.1 Глухая оборона (мгновенная, self)

- Каст мгновенный (не `aiPreparable`), действует сразу после применения. `apCost 1`, `cooldown 4`.
- Накладывает на босса статус `bulwark` («Глухая оборона») длительностью 1 ход:
  - **Иммунитет к любому урону**: прямой, AoE, тики статусов, урон столкновений. (Реализация: движковое обнуление в `applyDamageToEntity` при статусе `bulwark` у цели; событие `ENTITY_DAMAGED` с damage 0 эмитится, поэтому статусы накладываются как обычно. Вариант с правилом `modifyDamage multiply 0` отклонён — не покрывает DAMAGE_TILE; пол «минимум 1 урона» снят из расчёта урона 2026-08-10.)
  - **Иммунитет к перемещающим эффектам**: PUSH/толчки не сдвигают босса.
  - **Статусы накладываются как обычно**: `dazed`/`burning`/`stunned`/`silenced` работают — это сохраняет контрплей срыва подготовки.
  - **Полный запрет действий носителя**: пока статус активен, босс не может двигаться, атаковать и кастовать. Ключевое отличие от `stunned`: подготовленный скилл **не сбрасывается**.
- Тайминг: накладывается в конце хода босса → действует весь ход игрока → снимается тиком в начале следующего хода босса (перед исполнением подготовленного скилла).

### 3.2 Налёт (подготавливаемый)

- Исполнение — как у существующего `swoop`: прыжок в свободную клетку, урон по квадрату 3×3 вокруг точки приземления, PUSH всех живых от центра. `apCost 2`, `cooldown 2`, `aiPreparable`.
- Отличие босс-варианта: **дальность прыжка 3 клетки** (у базового swoop — 2), чтобы догонять дальнобойного игрока.
- **Приоритет цели — столкновение**: выбирается точка приземления, с которой толчок игрока заканчивается столкновением с препятствием (стена, объект, другой актор). Столкновение даёт урон и `dazed` на 2 хода существующими глобальными правилами (`collision_damage`, `collision_daze`); `dazed` открывает крит-уязвимость (`core_crit_on_dazed_stunned`) — босс добивает критом.
- **Если точки со столкновением нет — скилл придерживается** (не кастуется); босс продолжает обычный бой до появления удачной геометрии.

### 3.3 Удар по земле (подготавливаемый)

- Тупой (blunt, физический — вычитается бронёй) урон по площади радиуса 2 (квадрат 5×5) **вокруг босса** + `dazed` всем выжившим. `apCost 2`, `cooldown 4`, `aiPreparable`.
- Бьёт по **всем** существам в зоне, кроме кастера (friendly fire по другим врагам допустим).
- Телеграф: на время подготовки опасная зона подсвечивается — так же, как сейчас подсвечивается зона Налёта.

## 4. Стадии боя

### Стадия 1 (HP > 50%)

Босс преследует игрока и атакует в ближнем бою (hunter-поведение). Налёт — единственный скилл стадии.

Приоритеты хода:
1. Есть подготовленный Налёт → исполнить, затем продолжить ход по оставшимся AP.
2. Иначе — преследование и ближняя атака, пока есть AP и смысл действий.
3. В конце хода (AP израсходованы или дальнейшие действия бессмысленны): если Налёт доступен (кулдаун 0) **и** существует точка приземления со столкновением игрока → подготовить Налёт. Иначе — конец хода.

### Переход на стадию 2 (первое пересечение порога 50% HP)

- **MVP:** срабатывает в начале ближайшего хода босса — проверка порога в начале хода. Это **исключение** из правила «сначала израсходовать действия»: босс немедленно готовит Удар по земле и кастует Глухую оборону, ход заканчивается.
- **Пост-MVP (отложено):** немедленная реакция в момент пересечения порога (даже посреди хода игрока). Вынесено в отложенные доработки.

### Стадия 2 (HP ≤ 50%)

Приоритеты хода:
1. Есть подготовленный скилл → исполнить, затем продолжить ход по оставшимся AP.
2. **Комбо** (приоритет над Налётом): если Глухая оборона и Удар по земле оба доступны (кулдаун 0) — босс расходует AP на преследование/атаку, в конце хода готовит Удар по земле и кастует Глухую оборону. Оборона защищает подготовку в ход игрока и спадает тиком перед следующим ходом босса — Удар исполняется уже без обороны.
3. Иначе, если Налёт доступен и есть точка со столкновением — как в стадии 1 (преследование, подготовка в конце хода).
4. Иначе — обычное преследование и атака.

Порядок внутри комбо-хода: действия → подготовка Удара → каст Обороны → конец хода (Оборона запрещает действия, поэтому кастуется последней).

## 5. Контрплей игрока

- **Налёт:** телеграф на ход; не стоять спиной к стенам/объектам — без геометрии столкновения босс скилл придерживает; выйти из зоны до исполнения (цели фиксируются при подготовке).
- **Удар по земле:** увидеть подсветку зоны и отойти на 3+ клетки от босса; Глухая оборона делает босса неуязвимым на этот ход — урон тратить бессмысленно, окно для отступления или перестроения.
- **Срыв подготовки:** `stunned`/`silenced` сбрасывают подготовленный скилл — Оборона от статусов не защищает. Оглушение босса в комбо-ход сжигает и подготовку, и потраченную Оборону.
- **Дальний бой:** уязвимые окна — ходы без Обороны; Налёт (дальность 3) наказывает за кайтинг вдоль стен.

## 6. Доработки движка (объём фазы реализации)

1. Статус `bulwark` + движковый иммунитет к урону (обнуление в `applyDamageToEntity`; пол min-1 снят 2026-08-10); иммунитет носителя к PUSH; блокировка MOVE/ATTACK/USE_ABILITY для носителя **без сброса подготовленного скилла**.
2. Обобщённый исполнитель self-buff способности (по roadMap 1.3): статус/длительность из шаблона вместо захардкоженного `counterattackSkill` — для Глухой обороны.
3. Босс-вариант Налёта: дальность прыжка 3 (параметризация констант swoop или отдельный исполнитель — решить при реализации, предпочтительно параметризация).
4. Новый исполнитель «Удар по земле»: AoE квадрат 5×5 вокруг кастера, blunt-урон + `dazed` выжившим, по всем существам кроме кастера.
5. Тактика выбора точки Налёта «приземление → столкновение игрока с препятствием» в `src/simulation/ai/tactics/`; при отсутствии такой точки — скилл недоступен стратегии.
6. Новая AI-стратегия босса: hunter-базис + отложенная подготовка скиллов в конце хода + две стадии (проверка порога 50% HP в начале хода, одноразовый переход) + приоритет комбо над Налётом.
7. Подсветка зоны подготовленного Удара по земле в presentation — по образцу существующей подсветки Налёта.
8. Контент: шаблоны трёх способностей, статуса `bulwark`, правил иммунитета/dazed; обновление `cat_guardian` (способности, `aiStrategyId`, `isBoss` — в рамках roadMap 1.3); тексты ru/en.

## 7. Отложенное

- Немедленная реакция перехода стадий (прерывание в момент пересечения порога, в т.ч. посреди хода игрока) — после полной реализации босса.

## 8. Протокол решений (2026-08-10)

| Вопрос | Решение |
|---|---|
| Ошеломление от столкновения Налётом | `dazed` из существующих глобальных правил (без `stunned`) |
| Дальность прыжка Налёта | 3 клетки (босс-вариант) |
| Нет геометрии столкновения | Налёт придерживается |
| Иммунитет Обороны | Урон — полный; толчки — иммунитет; статусы — уязвим |
| Действия под Обороной | Запрещены все (движение, атака, каст) |
| Эффекты Удара по земле | Урон + `dazed` выжившим |
| Friendly fire AoE | Да, по всем существам кроме кастера |
| Тайминг перехода стадий | MVP — в начале хода босса; немедленная реакция — отложена |
| Приоритет на стадии 2 | Комбо по кулдауну, Налёт заполняет окна |
| Кулдауны | Оборона 4, Удар 4 (синхронны), Налёт 2 |
| Числа (HP/урон) | Балансный проход позже; порог стадий — 50% |
| Телеграф зон | Подсветка зоны, как у Налёта сейчас |
| Реализация иммунитета Обороны | Движковое обнуление в `applyDamageToEntity` (не `modifyDamage multiply 0` — не покрывает DAMAGE_TILE); пол min-1 снят из расчёта урона, сохранён только для процентного урона (`min: 1` в правилах) |
